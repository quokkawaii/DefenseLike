게임 시스템의 변경 26-09-30

1. 층수 줄이기 ( 플레이어의 루즈함 + 템이 너무 빠르게 돌아가야됨 )

- 최대 층수를 50층으로 제한.
- 층마다 나오는 몬스터의 수를 증가
- 이에 따른 스테이지는 1~10 / 11~20 / 21~30 / 31~40 / 41~50으로 한 런 (랜덤 5종족)

1-1. 다음 종족/원소 공개

- 현재 스테이지의 종족/원소와 다음 스테이지의 종족/원소를 표시한다. (10층 구간)
- 예 : 현재 층 : 5 -> 현재 스테이지 -> 1층 ~ 10층, 다음 스테이지 -> 11층 ~ 20층
- 런 포기후 재시작하면 리세마라가 되게 설정

2. 맵 변경

- 한 명이 두 필드를 동시에 방어한다.
- 기존 논리상 위 필드는 화면 왼쪽, 아래 필드는 화면 오른쪽에 배치한다. 두 유닛 필드는 겹치지 않고 중앙의 몬스터 경로 한 열만 같은 화면 좌표를 공유한다.
- 사거리가 된다면 아래의 유닛도 위의 필드의 몬스터를 때릴 수 있음. 반대의 경우도 가능
- 몬스터 생성비율은 위, 아래 필드 동일함
- 위,아래의 필드는 하나의 필드처럼 모든 상호작용이 가능함 (승급, 필드이동 등)
- 특정 보스의 특수능력으로는 다른 필드로 이동 가능하다.
- 스크롤은 필드별로 대상을 고름 (어차피 그렇게 범위가 길지 않을텐데)
- 왼쪽 필드 몬스터는 왼쪽 위에서 나와 위쪽 경로를 오른쪽으로 이동한다.
- 오른쪽 필드 몬스터는 오른쪽 위에서 나와 위쪽 경로를 왼쪽으로 이동한다. 양쪽 몬스터는 위쪽 중앙에서 합류해 중앙 공유 열을 아래로 이동하고 아래쪽에서 좌우로 갈라진다.
- 위 아래는 각각 4x6 필드이다. (총 48칸)
- 경로 룰은 현재 사용중인 룰을 사용한다.
- 몬스터는 공격능력이 없음을 다시한번 명시한다.
- 총 필드몬스터는 위,아래의 필드를 합친 값이다.
- 보스는 일정 확률로 위,아래 총 2마리가 나오게 설정한다. (20퍼센트 확률), 하나가 나올 경우 위, 아래 둘중 랜덤으로 등장
- 보스 처치시 필드 몬스터 제거하는 설정은 삭제한다. 보스 몬스터를 처치해도 몬스터는 그대로 유지한다.
- 2보스일 경우 2보스 모두 처치시 클리어이다. ( 2 보스의 경우 인게임 보상도 2번 적용, 증강도 2개 나옴)
- 제한시간도 공통이다.
- 보스 스테이지에서는 일반 몬스터 등장하지않음
- 보스같은 경우 처치시 바로 다음 스테이지로 넘어감.(50층의 경우 바로 게임 승리)
- 유닛 배치 칸이고, 경로는 그 바깥을 도는 별도 칸 (기존 룰 그대로)
- 타겟 : 사거리 안의 두 경로 몬스터 중 누적 진행도가 가장 앞선 몬스터

### 궁수

#### 다중 사격

궁수가 공격할 때 하나의 대상만 공격하지 않고 사거리 내 여러 몬스터를 동시에 대상으로 지정한다.

최대 3명의 몬스터를 대상으로 각각 화살을 발사하며, 대상은 기존 궁수의 타겟 선정 규칙을 따른다.

- 최대 대상 수: 3명
- 각 화살 피해: 기존 화살 피해의 70%
- 동일한 대상을 중복 지정하지 않는다.

강화 화살을 보유하고 있을 경우 발사되는 화살마다 강화 화살을 1개씩 소비한다.

예를 들어 강화 화살을 2개 보유한 상태에서 다중 사격이 발동하면 우선순위가 높은 2개의 화살은 강화 화살로 발사되고 나머지 1발은 일반 화살로 발사된다.

S등급의 강화 화살 무제한 상태에서는 다중 사격으로 발사되는 모든 화살이 강화 화살로 발사된다.

다른 궁수 플래티넘 증강과 함께 사용할 수 있다.

예를 들어 다중 사격 + 관통 화살을 보유한 경우 3명의 몬스터에게 각각 관통 화살을 발사한다.

#### 관통 화살

궁수가 발사한 화살이 첫 번째 몬스터에게 적중한 뒤 사라지지 않고 추가 몬스터를 관통한다.

- 하나의 화살은 최대 3명의 몬스터에게 피해를 줄 수 있다.
- 관통 피해는 해당 화살 피해의 100%를 적용한다.
- 첫 번째 대상에 적중하면 기존 유도 효과를 종료한다.
- 첫 번째 대상에게 적중하는 순간 화살이 이동하고 있던 방향을 기준으로 직선으로 계속 이동한다.
- 이후 해당 직선 경로와 충돌하는 몬스터를 순서대로 관통한다.

다중 사격과 함께 적용될 경우 각각의 화살에 관통 효과가 적용된다.

#### 폭발 화살

궁수의 화살이 몬스터에게 적중하면 적중 위치를 중심으로 추가 범위 피해가 발생한다.

- 폭발 반경: 1블럭
- 폭발 피해: 해당 화살 직접 피해의 45%
- 직접 적중한 대상은 해당 폭발 피해에서 제외한다.

관통 화살과 함께 적용될 경우 관통 과정에서 적중한 몬스터마다 폭발 효과가 발생한다.

다중 사격까지 동시에 적용될 경우 여러 개의 화살에서 각각 폭발이 발생할 수 있다.

### 단법

#### 마탄 폭주

단법의 스킬 사용 시 발사되는 마탄의 개수가 증가한다.

기존 스킬의 타겟 선정 및 마탄 발사 구조는 유지하면서 한 번의 스킬 사용으로 더 많은 마탄을 발사한다.

- D등급: 5발 → 9발
- C등급: 7발 → 11발
- B등급: 9발 → 13발
- A등급: 12발 → 16발
- S등급: 마탄 발사 간격 0.3초 → 0.2초

기존 마탄 피해량과 스킬 지속시간은 변경하지 않는다.

다른 단법 플래티넘 증강과 중복 적용할 수 있다.

#### 집중 포격

단법이 스킬을 사용할 때 여러 몬스터에게 마탄을 분산하지 않고 하나의 몬스터에게 집중적으로 발사한다.

- 마탄 피해: 기존 마탄 피해의 180%
- 대상 선정: 기존 타겟 우선순위를 따른다.

현재 대상이 스킬 도중 처치될 경우 아직 발사하지 않은 남은 마탄은 다음 공격 가능한 몬스터를 대상으로 지정한다.

집중 포격을 보유하고 있을 경우 D~A등급에서도 기존의 `대상 사망 시 남은 미사일 취소` 규칙을 적용하지 않고 다음 대상으로 발사를 이어간다.

이미 발사된 마탄의 대상 사망 처리는 기존 규칙을 따른다.

마탄 폭주와 함께 사용할 경우 증가한 마탄 전체가 하나의 대상을 집중 공격한다.

#### 폭발 마탄

마탄이 몬스터에게 적중할 때 적중 위치를 중심으로 범위 피해가 추가로 발생한다.

- 폭발 반경: 1블럭
- 폭발 피해: 해당 마탄 직접 피해의 45%
- 직접 적중한 대상은 폭발 피해에서 제외한다.

마탄 한 발마다 폭발 효과를 발생시킬 수 있다.

마탄 폭주와 함께 적용할 경우 증가한 마탄 각각에 폭발 효과가 적용된다.

집중 포격과 함께 적용하면 하나의 대상 주변에 연속적인 폭발 피해를 줄 수 있다.

### 전사

#### 회전 베기

전사의 기존 광역 스킬을 한 번만 발동하지 않고 짧은 간격으로 여러 번 반복한다.

- 공격 횟수: 3회
- 공격 간격: 0.12초
- 각 공격 피해: 기존 스킬 피해의 100%

각 공격은 기존 광역 스킬의 범위 판정을 사용한다.

각 타격 시점마다 범위 안에 있는 몬스터를 다시 판정하여 피해와 기존 스턴 효과를 적용한다.

이미 스턴 상태인 몬스터가 다시 공격받으면 스턴 시간이 누적되지 않고 해당 등급의 스턴 지속시간으로 갱신된다.

#### 대지 강타

전사의 기존 광역 스킬의 공격 범위와 피해량을 증가시키고 스턴 효과를 강화한다.

- 공격 범위: 기존 범위 +40%
- 스킬 피해: +30%
- 스턴 지속시간: +100%

기존 전사의 광역 공격과 상태이상 구조를 그대로 사용한다.

회전 베기와 함께 적용될 경우 반복되는 3회의 공격 모두 대지 강타의 증가된 범위, 피해량, 스턴 지속시간을 적용한다.

#### 충격파

전사가 기존 근거리 광역 공격을 사용한 뒤 전방에 추가적인 범위 공격을 발생시킨다.

전방은 스킬 시전 시 전사 위치에서 기존 타겟 선정 규칙으로 선택된 몬스터 방향을 기준으로 한다.

- 충격파 중심: 전사 위치에서 대상 방향으로 2블럭
- 충격파 반경: 1.5블럭
- 충격파 피해: 기존 전사 스킬 피해의 100%
- 충격파에는 스턴을 적용하지 않는다.

첫 번째 공격은 기존 전사 주변 범위를 공격하고 이후 전방에 위치한 몬스터에게 충격파 피해를 준다.

회전 베기와 함께 적용될 경우 회전 공격 3회를 모두 실행한 뒤 마지막에 충격파를 1회 발생시킨다.

### 광법

#### 거대 마법진

광법이 생성하는 장판의 범위를 증가시킨다.

- 장판 범위: 기존 장판 범위 +2블럭

등급별 장판 범위는 다음과 같이 변경된다.

- D등급: 1블럭 → 3블럭
- C등급: 2블럭 → 4블럭
- B등급: 3블럭 → 5블럭
- A등급: 4블럭 → 6블럭
- S등급: 5블럭 → 7블럭

장판의 기본 지속시간과 공격 방식, 타격당 피해량은 유지한다.

#### 고속 마법진

광법 장판의 피해 발생 간격을 감소시킨다.

- 기존 피해 주기: 1초
- 변경 피해 주기: 0.35초
- 장판 지속시간: 기존 3초 유지
- 타격당 피해: 기존 장판 피해의 100%

장판 생성 즉시 첫 피해를 발생시키고 이후 약 0.35초마다 피해를 발생시킨다.

거대 마법진과 함께 적용할 경우 넓어진 범위에 더 빠른 주기로 피해를 줄 수 있다.

#### 이중 마법진

광법이 스킬을 사용할 때 장판을 하나가 아닌 두 개 생성한다.

- 장판 생성 수: 2개

첫 번째 장판은 기존 타겟 선정 규칙에 따라 선택된 몬스터를 기준으로 생성한다.

두 번째 장판은 사거리 안에서 다음 타겟 우선순위를 가진 몬스터를 기준으로 생성한다.

두 번째 유효 대상이 존재하지 않는 경우 첫 번째 장판과 같은 위치에 생성한다.

각 장판은 독립적으로 피해를 발생시키며 두 장판이 겹칠 경우 각각의 장판 피해가 모두 적용된다.

거대 마법진과 고속 마법진을 함께 보유하고 있을 경우 생성되는 두 장판 모두 해당 효과를 적용받는다.

### 도적

#### 연속 강탈

도적이 강탈 스킬을 사용할 때 동일한 대상에게 스킬을 두 번 연속 실행한다.

- 강탈 횟수: 2회
- 공격 간격: 0.13초
- 각 타격 피해: 기존 강탈 피해의 100%
- 각 공격마다 기존 강탈 재화 획득 규칙을 적용한다.

각 공격마다 피해와 강탈 판정을 각각 수행한다.

첫 번째 공격으로 대상이 처치될 경우 두 번째 공격은 발생하지 않는다.

#### 광역 강탈

도적의 강탈 스킬이 적중한 몬스터 주변의 다른 몬스터에게도 추가 피해를 준다.

- 광역 범위: 대상 중심 반경 1.5블럭
- 주변 몬스터 피해: 기존 강탈 피해의 50%
- 직접 강탈 대상은 광역 추가 피해에서 제외한다.

광역 강탈에 적중한 주변 몬스터에게 실제로 적용된 피해량만큼 인게임 재화를 추가로 획득한다.

도적의 단일 대상 강탈 능력을 다수의 몬스터를 대상으로 사용할 수 있도록 확장하는 증강이다.

#### 대박 강탈

도적이 강탈로 인게임 재화를 획득할 때 일정 확률로 획득 재화가 크게 증가한다.

- 발동 확률: 20%
- 발동 시 획득 재화: 기존 획득량의 3배

기본 강탈 판정은 그대로 유지한다.

연속 강탈과 함께 사용할 경우 각 강탈마다 대박 강탈 확률을 별도로 판정한다.

광역 강탈과 함께 사용할 경우 직접 강탈 대상과 광역 강탈로 발생하는 각 재화 획득에도 대박 강탈 확률을 각각 독립적으로 판정한다.

### 중복 적용

직업별 플래티넘 증강은 서로 배타적으로 적용되지 않는다.

같은 런에서 동일 직업의 플래티넘 증강을 여러 개 획득하면 모든 효과를 동시에 적용한다.

#### 궁수

`다중 사격 + 관통 화살 + 폭발 화살`

- 최대 3명의 대상에게 각각 화살을 발사한다.
- 각 화살은 기존 피해의 70%를 적용한다.
- 각각의 화살이 최대 3명의 몬스터를 관통한다.
- 화살이 몬스터에게 적중할 때마다 반경 1블럭의 폭발 피해가 발생한다.

#### 단법

`마탄 폭주 + 집중 포격 + 폭발 마탄`

- 등급에 따라 증가한 수의 마탄을 발사한다.
- 마탄은 하나의 대상을 집중 공격한다.
- 각 마탄의 피해가 기존의 180%로 증가한다.
- 대상이 사망하면 남은 마탄을 다음 대상으로 발사한다.
- 각각의 마탄 적중 시 반경 1블럭의 폭발 피해가 발생한다.

#### 전사

`회전 베기 + 대지 강타 + 충격파`

- 공격 범위가 40% 증가한다.
- 스킬 피해가 30% 증가한다.
- 스턴 지속시간이 100% 증가한다.
- 강화된 광역 공격을 0.12초 간격으로 3회 실행한다.
- 마지막 회전 공격 이후 전방에 충격파를 1회 발생시킨다.

#### 광법

`거대 마법진 + 고속 마법진 + 이중 마법진`

- 기존보다 2블럭 넓어진 장판을 2개 생성한다.
- 두 장판 모두 0.35초 간격으로 피해를 발생시킨다.
- 두 장판이 겹칠 경우 각각 독립적으로 피해를 적용한다.

#### 도적

`연속 강탈 + 광역 강탈 + 대박 강탈`

- 동일한 대상에게 최대 2회의 강탈을 실행한다.
- 각 강탈마다 주변 1.5블럭의 몬스터에게 기존 강탈 피해의 50%를 추가로 준다.
- 직접 강탈과 광역 강탈 모두 실제 피해량을 기준으로 재화를 획득한다.
- 각각의 재화 획득마다 20% 확률로 획득량이 3배 증가한다.

5. 연출
   목적

기존 인게임의 성장·타격·보상 체감이 부족한 부분을 보완한다.

인게임 전투가 중심이므로 연출이 전투 가독성을 방해하지 않게 한다.

기존 디자인 요구사항에 이미 정의된 연출은 본 문서에서 중복 작성하지 않는다.

1. 공통 연출 원칙

연출은 유닛 또는 발생 위치 주변의 국소 연출을 우선한다.

위·아래 두 필드 중 한쪽의 연출이 반대쪽 필드를 가리지 않아야 한다.

화면 전체를 가리는 연출은 최소화한다.

빠른 반복 점멸은 사용하지 않는다.

화면 흔들림과 장식성 이펙트는 기존 설정의 이펙트 표시량·화면 흔들림 설정을 따른다.

몬스터 수 증가를 고려하여 반복되는 공격·처치 연출은 짧게 유지한다.

2. 유닛 승급 연출

D → C → B → A → S 승급 시 성장 체감을 강화한다.

연출

승급 대상 유닛 주변에 짧은 국소 이펙트를 표시한다.

승급된 등급을 유닛 근처에 짧게 표시한다.

짧은 승급 효과음을 재생한다.

승급 완료 후 변경된 유닛 외형과 등급별 스킬 모션을 즉시 적용한다.

강도

D → C : 기본

C → B : 기본

B → A : 강조

A → S : 가장 강하게 강조

제한

화면 전체 연출을 사용하지 않는다.

별도의 승급 결과 화면을 열지 않는다.

반대쪽 필드의 전투를 가리지 않는다.

3. 크리티컬 타격 연출

랜덤 버프 시스템으로 크리티컬이 추가되므로 일반 피해와 크리티컬 피해를 구분한다.

기존 피해 숫자의 색상은 원소 상성 결과 구분에 계속 사용한다.

크리티컬은 새로운 피해 색상을 추가하지 않는다.

크리티컬 발생 시 피해 숫자의 크기 또는 짧은 확대 효과를 사용하여 일반 피해와 구분한다.

반복적인 화면 흔들림이나 전체 화면 효과는 사용하지 않는다.

구체적인 크리티컬 숫자 크기와 확대 시간은 시각 디자인 단계에서 결정한다.

4. 랜덤 버프 적용 연출

랜덤 버프가 결정되면 해당 버프가 적용되었다는 사실을 짧게 전달한다.

버프 결정 직후 적용된 버프를 짧게 표시한다.

양쪽 필드 전체 유닛에 적용되는 효과이므로 화면 전체를 덮는 연출 대신 짧은 공통 적용 효과를 사용한다.

적용 효과가 유닛·몬스터·공격 이펙트를 가리지 않아야 한다.

동일 버프 중첩 시 최초 적용과 동일한 긴 연출을 반복하지 않는다.

버프의 지속시간·중첩·현재 상태를 표시하는 UI는 연출 문서가 아닌 인게임 UI 요구사항에서 관리한다.

5. 증강 획득 연출

증강 선택 화면과 정보 구조는 별도 UI 요구사항에서 관리한다.

본 문서에서는 증강을 획득하는 순간의 연출만 정의한다.

증강을 선택하면 선택한 증강 카드에 짧은 선택 완료 효과를 적용한다.

선택 완료 후 별도의 결과 화면을 추가하지 않고 인게임으로 복귀한다.

실버·골드·플래티넘의 등급 차이는 증강 카드 디자인으로 구분하며 과도한 전체 화면 효과를 사용하지 않는다.

새로고침 등급 상승

새로고침으로 증강 등급이 상승한 경우

기존 카드가 변경되는 순간에만 짧게 강조한다.

별도의 전체 화면 연출이나 긴 애니메이션은 사용하지 않는다.

6. 두 마리 보스 연출

보스가 두 마리 등장하더라도 새로운 대형 전용 연출은 추가하지 않는다.

각 보스는 기존 보스 등장 연출 규칙을 사용한다.

두 필드의 보스 위치를 동시에 확인할 수 있어야 한다.

DOUBLE BOSS 등의 별도 전체 화면 연출은 사용하지 않는다.

한 보스를 처치했을 때 다른 보스의 전투 흐름을 끊는 연출을 사용하지 않는다.

보스 처치 문구·전용 효과음을 사용하지 않는 기존 규칙은 유지한다.

7. 50층 최종 보스

50층 최종 보스도 기존 보스 처치 연출 규칙을 기본으로 사용한다.

일반 보스보다 사망 모션 자체를 약간 강조할 수 있다.

별도의 VICTORY 중간 연출 화면은 추가하지 않는다.

보스 처치 이후 기존 정산 결과 화면으로 전환한다.

일반 몬스터를 보스 처치 연출로 제거하지 않는다.

8. 연속 처치 연출

현재는 적용하지 않는다.

몬스터 스폰 수 증가 후 실제 플레이테스트에서 대량 처치 체감이 부족하다고 판단될 경우 별도 요구사항으로 추가한다.

KILL, COMBO 등의 화면 표시를 현재 정본에는 포함하지 않는다.

기존 요구사항에서 그대로 사용하는 연출
