# DefenseLike 게임 개발 순서

작성일: 2026-10-06

1~3단계는 사용자가 지정한 우선순위다. 4단계 이후는 아래 공식 문서의 순서를 참고해 정했으며, 공식 문서 내용을 이 게임에 대응시킨 부분은 `판단`으로 표시한다. 9단계 이후는 아직 정하지 않았다.

## 참고한 공식 문서

- Phaser, [Making your first Phaser game](https://docs.phaser.io/phaser/getting-started/making-your-first-phaser-game): 에셋 로드 → 이미지 표시 → 월드(맵) 구성 → 플레이어 캐릭터 → 물리 → 입력 → 수집 아이템 → 점수 표시 → 적 순서로 진행한다.
- Phaser, [Scenes](https://docs.phaser.io/phaser/concepts/scenes): Scene은 `init → preload → create → update` 순서로 동작하며, 로딩 화면·메인 메뉴·게임 레벨·상점 등을 Scene으로 나누는 것을 대표적인 사용 예로 든다.
- 한계: 공식 문서는 튜토리얼 수준의 순서만 제공한다. 디펜스 게임 구조·아웃게임·저장에 대한 개발 순서는 공식 문서에 없다.

## 단계별 주의 사항

- 1~2단계는 시각 디자인(3단계) 전에 진행하므로 맵과 캐릭터를 임시 도형으로 표시한다.
- 2단계의 전사는 배치만 다루므로 개발 중 보고 대상에 걸리지 않는다. 5단계에서 전사의 기본 공격을 구현할 때는 광역 범위 충돌(B4: `GAME-058` ↔ `GAME-057`·`GAME-257`)을 먼저 사용자에게 보고하고 결정을 받아야 한다. 보고 대상 목록은 `docs/interview/interview-state.md`의 `개발 중 보고 대상`을 따른다.
- 각 단계의 순수 규칙 계산은 Phaser에 의존하지 않게 작성하고 Vitest로 테스트한다(`SYS-132`, `SYS-074`). 파일 위치는 `SYS-134`를 따른다.
