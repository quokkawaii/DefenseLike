# 해당 파일은 유닛의 컨셉을 정하는 파일이다.
# 유닛는 각 d ~ s등급까지 있으며 스킬이 강화되는 형식이다.
# 등급이 오르면 고정 스탯도 오른다.

# 단일 = 보스, 광역 = 일반 몬스터들에 특화 되어있다. (재화 관련 유닛은 약함)
# 등급별로 데미지도 증가하며, 스킬 모션도 다르다.
# 원소마다 평타,스킬 색깔이 다름
# 스킬 시전중에는 평타는 안나간다. (버프형 스킬 제외)

# v1.1 전투 능력치
- 크리티컬 임시 가값은 기본 확률 5%, 피해 배율 150%, 확률 상한 100%다. 크리티컬 확률·피해 배율과 방어 관통률 증가는 퍼센트포인트로 가산하며 확률과 관통률은 100%를 상한으로 한다. 방어 관통은 대상 방어력에 관통률을 곱해 차감한 유효 방어력으로 피해를 계산한다. 이 수치와 계산식은 큰 틀 검증용 가값이며 플레이테스트 전에 조정한다. (v1.1 가값)
- 랜덤 버프의 `AD·AP +50%`는 양쪽 필드의 모든 유닛에게 AD와 AP를 함께 올린다. (v1.1)

## 실버
- 모든 원거리 유닛 사거리 +1블럭, 공격속도 +10%, AD +10%, AP +10%, 모든 몬스터 기본 이동속도 -10%, 근거리 유닛 피해 +10%, 원거리 유닛 피해 +10%, 스킬 쿨타임 -10%, 크리티컬 확률 +10%p, 크리티컬 피해 배율 +5%p, 방어 관통률 +10%p, 몬스터 처치 재화 +1골드, 보스 대상 피해 +10%, 일반 몬스터 대상 피해 +10%, 랜덤 골드 증강 1개 즉시 획득이 존재한다. (v1.1)

## 골드
- 모든 원거리 유닛 사거리 +2블럭, 속사(공격속도 +25%), 괴력(AD +25%), 마력 증폭(AP +25%), 저격수(원거리 피해 +20%), 광전사(근거리 피해 +30%), 약점 공략(방어 관통률 +25%p), 스킬 가속(모든 스킬 쿨타임 -20%), 처형자(HP 30% 이하 일반·보스 몬스터 피해 +30%), 보스 헌터(보스 피해 +30%), 학살자(일반 몬스터 피해 +25%), 치명적 공격(크리티컬 확률 +20%p·피해 배율 +30%p), 슬로우 필드(모든 몬스터 기본 이동속도 -20%), 현상금 사냥꾼(몬스터 처치 재화 +5골드), 스크롤 전문가(스크롤 최대 사용 횟수 +10), 원소 숙련(유리 상성 추가 피해율 절대값 +20%p), 역상성 극복(불리 상성 피해 감소율 절대값 20%p 완화·하한 0), 랜덤 플래티넘 증강 1개 즉시 획득이 존재한다. (v1.1)

## 플래티넘
- 궁수 `다중 사격`: 최대 3개의 서로 다른 우선순위 대상에게 기존 화살 피해의 70%인 화살을 각각 발사하며 강화 화살은 우선순위 순으로 발사체마다 1개 소비한다. S등급은 모든 발사체가 강화된다. (v1.1)
- 궁수 `관통 화살`: 첫 적중 뒤 유도를 끝내고 진행 직선상의 몬스터를 최대 3명까지 화살 피해 100%로 관통한다. (v1.1)
- 궁수 `폭발 화살`: 각 적중 위치 반경 1블럭에 직접 적중 대상을 제외하고 직접 피해의 45% 폭발 피해를 준다. 관통 적중마다 각각 발생한다. (v1.1)
- 단법 `마탄 폭주`: D/C/B/A 마탄 수를 9/11/13/16발로 바꾸고 S 발사 간격을 0.2초로 바꾼다. 기존 피해와 지속시간은 유지한다. (v1.1)
- 단법 `집중 포격`: 마탄 피해를 기존의 180%로 올리고 모든 미발사 마탄을 우선순위가 가장 높은 한 대상에게 집중한다. 대상 사망 시 남은 마탄은 다음 유효 대상으로 이어서 발사한다. (v1.1)
- 단법 `폭발 마탄`: 각 마탄 적중 위치 반경 1블럭에 직접 적중 대상을 제외하고 직접 피해의 45% 폭발 피해를 준다. (v1.1)
- 전사 `회전 베기`: 기존 광역 스킬을 0.12초 간격으로 3회 사용하고 각 타격은 기존 스킬 피해 100%와 기존 스턴을 적용한다. 스턴은 누적하지 않고 등급별 지속시간으로 갱신한다. (v1.1)
- 전사 `대지 강타`: 기존 광역 스킬 범위 +40%, 피해 +30%, 스턴 지속시간 +100%를 적용한다. (v1.1)
- 전사 `충격파`: 기존 공격 뒤 선택 대상 방향 2블럭 지점을 중심으로 반경 1.5블럭에 기존 스킬 피해 100%의 추가 피해를 주며 스턴은 적용하지 않는다. 회전 베기와 함께면 세 번째 타격 뒤 한 번 발생한다. (v1.1)
- 광법 `거대 마법진`: 장판 범위를 +2블럭 하여 D/C/B/A/S를 3/4/5/6/7블럭으로 바꾸고 지속시간·공격 방식·타격당 피해는 유지한다. (v1.1)
- 광법 `고속 마법진`: 장판 생성 즉시 피해를 준 뒤 기존 3초 동안 약 0.35초마다 기존 장판 피해 100%를 준다. (v1.1)
- 광법 `이중 마법진`: 장판을 2개 생성한다. 첫 장판은 첫 우선순위 대상, 둘째는 다음 대상에게 생성하고 둘째 대상이 없으면 같은 위치에 겹친다. 두 장판은 독립 피해를 준다. (v1.1)
- 도적 `연속 강탈`: 같은 대상에게 0.13초 간격으로 기존 강탈 피해 100%의 강탈을 2회 적용한다. 첫 공격으로 대상이 죽으면 두 번째 공격은 발생하지 않는다. (v1.1)
- 도적 `광역 강탈`: 직접 대상 주변 반경 1.5블럭의 다른 몬스터에게 기존 강탈 피해의 50%를 주고 실제 적용 피해만큼 인게임 재화를 얻는다. (v1.1)
- 도적 `대박 강탈`: 각 강탈 재화 획득마다 독립적으로 20% 확률로 획득량을 3배로 한다. (v1.1)
- 같은 직업의 플래티넘 증강은 서로 배타적이지 않으며 같은 런에서 모두 중복 적용한다. 세 증강의 결합 결과는 각 항목의 개별 효과와 명시된 연계 순서를 함께 적용한다. 모든 수치는 초기 플레이테스트 값이다. (v1.1)
