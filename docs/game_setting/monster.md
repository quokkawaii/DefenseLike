# 해당 파일은 몬스터 종족 설정 파일이다.

# v1.1 공통 규칙
- 몬스터는 공격 능력을 가지지 않고 이동과 종족별 특수능력만 사용한다. (v1.1)
- 각 10층 구간의 4~9번째 층에는 특수 몬스터가 각각 1·2·3·4·5·6마리 등장하며, 해당 층의 일반 몬스터 생성 순서 사이에 배치한다. 특수 몬스터는 층별 총 생성 수에 포함한다. (v1.1)
- 위·아래 두 경로의 몬스터 수를 합친 값을 현재 필드 몬스터 수로 사용한다. (v1.1)
- 별도 제한 없이 `필드의 몬스터` 또는 거리 제한 없는 대상을 가리키면 위·아래 두 경로의 살아 있는 몬스터 전체를 뜻한다. 반지름·거리 범위는 실제 화면 공간을 기준으로 하므로 반대 경로의 몬스터도 범위 안에 있으면 영향을 받는다. 스크롤만 선택한 한 필드로 범위를 제한하고, 경로 이동은 능력에 명시된 경우에만 허용한다. (v1.1)
- 보스는 20% 확률로 위·아래 경로에 각각 한 마리씩 등장하고, 그 밖에는 두 경로 중 하나에 무작위로 한 마리 등장한다. 두 보스는 공통 제한시간을 사용하며 모두 처치해야 보스 층을 클리어한다. (v1.1)
- 보스를 처치해도 이미 필드에 남아 있는 일반 몬스터는 제거하거나 처치 처리하지 않는다. (v1.1)
- 보스의 특수능력에 필드 간 이동이 포함된 경우 위·아래 경로 사이를 이동할 수 있다. (v1.1)

# 고블린

## 특징
- 체력 : 보통
- 이동속도 : 보통
- 약점 : 없음

## 종류
- 일반 고블린
- 샤먼 고블린 (체력 낮음, 힐러) : n초마다 힐 주변 ㅁㅁㅁ 만큼 힐 해줌
- 고블린 라이더 (멧돼지 탑승)

## 보스
- 고블린 킹 : 기믹 없음

# 슬라임

## 특징
- 체력 : 보통
- 이동속도 : 느림
- 약점 : 마법 피해

## 종류
- 일반 슬라임
- 분열 슬라임 (체력 낮음, 죽으면 일반 슬라임 2마리로 나뉨)
- 점프 슬라임 (n초 마다 2칸 점프)

## 보스
- 슬라임 킹 : 한번에 2~3칸 이동

# 스켈레톤

## 특징
- 체력 : 낮음
- 이동속도 : 보통
- 약점 : 마법 피해

## 종류
- 일반 스켈레톤
- 방패 스켈레톤 (체력 보통, 원거리 데미지 감소 = 2칸 이상 거리있음)
- 소환 스켈레톤 (n초 마다 일반 스켈레톤 소환)

## 보스
- 스켈레톤 킹 : 절반 hp로 다시 살아남, 이동속도 빠름

# 늑대

## 특징
- 체력 : 보통
- 이동속도 : 빠름
- 약점 : 마법 피해

## 종류
- 일반 늑대
- 굶주린 늑대 (체력이 적을수록 이동속도 빨라짐)
- 하울링 늑대 (n초마다 이동속도 버프 걸음)

## 보스
- 늑대 킹 : (필드에 살아있는 늑대 수의 비례하여 속도 빨라짐)

# 골렘

## 특징
- 체력 : 매우 높음
- 이동속도 : 느림
- 약점 : 없음

## 종류
- 일반 골렘
- 코어 골렘 (방어력이 높은 골렘, 맞으면 마법 방어력, 물리 방어력 감소)
- 재생 골렘 (n초마다 자기 자신의 피회복 )

## 보스
- 골렘 킹 : (이동속도 보통, 맞을수록 물마방어력이 오르고 이동속도 느려짐)

# 악마

## 특징
- 체력 : 보통
- 이동속도 : 보통
- 약점 : 물리 피해

## 종류
- 일반 악마
- 희생 악마 (죽으면 3칸 안의 아군에게 이동 속도 부여 3초)
- 무적 악마 (n초 마다 3칸 안의 아군에게 무적 버프 부여 2 초)

## 보스
- 악마 킹 : 체력 낮음, 정신 집중 n초 마다 각 필드의 모서리 중 한곳으로 탤포 (피격,cc기 걸리면 끊기고 정신 집중 초기화, 입장시 시작 지점 제외하고 3개의 모서리 중 하나로 이동)


# 드래곤
## 특징
- 체력 : 상
- 이동속도 : 보통
- 약점 : 물리 피해

## 종류

# 리자드맨

## 특징
- 체력 : 보통
- 이동속도 : 보통
- 약점 : 물리 피해

## 종류
- 일반 리자드맨
- 이동특화 리자드맨 : 자체 이속이 매우 빠른 개체
- 탱커특화 리자드맨 : 자체 물리,마법 방어가 매우 높은 개체

## 보스
- 리자드 킹 : n초마다 은신, 은신시 데미지 무시와 유닛의 타겟으로 안잡힘

# 뱀파이어

## 특징
- 체력 : 보통
- 이동속도 : 보통
- 약점 : 마법 피해

## 종류
- 일반 뱀파이어
- 포식 뱀파이어 (n초 마다 주변 뱀파이어 1마리 먹음, 피 회복 + 물마방 증가)
- 지휘관 뱀파이어 (n초 마다 주변 뱀파이어 물바방 증가 버프)


## 보스
- 뱀파이어 킹 : n초마다 일반 뱀파이어 소환, 뱀파이어가 주변에 존재하면 피 회복

# 정령

## 특징
- 체력 : 낮음
- 이동속도 : 빠름
- 약점 : 물리 피해

## 종류
- 일반 정령
- 물리 무시 정령 (n초 마다 물리 데미지 무시 2초)
- 마법 무시정령 (n초 마다 마법 데미지 무시 2초)

## 보스
- 정령 킹 : 주변에 정령이 있으면 데미지 무시
