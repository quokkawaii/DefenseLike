# 스크롤
# 사용 방법은 미리 깔아두는것이 아니라 즉시 구매하여 필드에 클릭하여 발동하는 형식이다.
# 위·아래 두 필드 중 적용할 필드를 구분한 뒤 해당 필드의 적용 지점을 선택한다. 스크롤의 범위 판정은 선택한 필드에 한정한다. (v1.1)
# 구매 회수 제한이 있다. (모든 스크롤 합쳐서 10번 구매 가능)
# 만약 필드위에 어떠한 몬스터/보스가 없다면 사용할 수 없음을 표시한다.
# 가격과 몬스터의 저항력은 정해지지 않았음. 몬스터의 저항력은 밸런스를 정할때

# 강제 텔레포트 스크롤 (해당 필드에 있는 몹 시작지점으로 텔포)

# 이속 감소 스크롤 (몬스터의 이동속도 30퍼 감소)

# 치유 감소 스크롤 (몬스터의 회복력 억제)

# 벽 생성 스크롤 (입구 앞에 설치 금지)

# 중력 제어 스크롤 (공중 몹 떨구기)

# 버프 해제 스크롤 (몬스터의 모든 버프를 제거함)

# 물마방 감소 스크롤 (물리 마방을 30퍼 감소)

# 빙결 스크롤 (n초간 몬스터를 빙결 상태)
