# DefenseLike 디자인 요구사항

이 문서는 게임·시스템 요구사항에서 파생되는 화면 구조, 조작, 피드백, 가독성과 접근성 요구사항 후보를 정의한다. `확정`·`승인`만 제작 근거로 사용하며 상태와 리뷰 방식은 `product-req.md`를 따른다. 시각 스타일을 임의로 확정하지 않는다.
