# DefenseLike 게임 요구사항 겸 기획서

이 문서는 전투, 성장, 경제와 콘텐츠 규칙의 정본이다. 상태와 리뷰 방식은 `product-req.md`를 따른다. 기존 문서에서 확정되지 않았다고 명시된 내용은 `미정`, 방향만 제시된 내용은 `제안`으로 보존한다.

## 20. 기획 검증 원칙

- ISO/IEC/IEEE 29148에 따라 각 요구사항을 하나의 검증 가능한 규칙으로 관리한다.
- 게임의 재미와 밸런스는 공식 표준이 결정하지 않는다. 사용자가 승인한 목표와 반복 플레이테스트 데이터로 검증한다.
- 수치가 없는 확정 규칙은 개발 전에 대응하는 `미정` 수치 항목을 승인해야 한다.
- 변경 시 연관된 `SYS-*`, `UX-*`, `PRD-*` 요구사항과 테스트에 미치는 영향을 함께 검토한다.
