# DefenseLike 시스템 요구사항

이 문서는 게임 기능을 지원하는 기술, 입력, 상태, 저장, 성능, 보안, 테스트 및 배포 요구사항을 정의한다. 상태와 리뷰 방식은 `product-req.md`를 따른다.

## 1. 기술 기준

| ID | 상태 | 요구사항 | 근거 | 검증 |
| --- | --- | --- | --- | --- |
| SYS-001 | 확정 | 소스 언어는 TypeScript를 사용한다. | 사용자 결정 | 프로젝트 설정 검사 |

| SYS-003 | 제안 | TypeScript `strict` 검사를 활성화한다. | TypeScript 공식 문서 | 타입 검사 |
| SYS-004 | 확정 | 백엔드 서버, WebSocket, 로그인과 DB를 사용하지 않는다. | `game-req.md` | 네트워크·의존성 검사 |
