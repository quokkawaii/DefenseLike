# DefenseLike 제품·출시 요구사항

이 문서는 게임·시스템·디자인 어느 한 영역에만 속하지 않는 사업, 사용자, 범위, 출시, 운영, 규정, 분석 및 리뷰 결정을 관리한다. 요구사항 문서는 기획 문서를 겸한다.

## 1. 리뷰 방법

상태는 다음 네 가지만 사용한다.

- `확정`: 사용자가 이미 결정한 사실
- `제안`: 공식 기준 또는 개발 완결성을 위해 제안한 내용
- `미정`: 선택지가 필요해 구현 근거로 사용할 수 없는 내용
- `승인`: 사용자가 검토 후 개발·디자인 근거로 승인한 내용

사용자는 `PRD-001 승인`, `PRD-014 수정: ...`, `PRD-021 보류`처럼 항목별로 답할 수 있다. `제안`과 `미정`은 승인 전까지 개발·디자인에 사용하지 않는다.

| `GAME-152`~`GAME-190` | `SYS-096`, `SYS-097` | `UX-136`~`UX-144` | 사건 순서·전투 경계·정보 표현 |
| `GAME-191`~`GAME-210` | `SYS-095`, `SYS-098`, `SYS-099`, `SYS-105` | `UX-103`~`UX-106`, `UX-145` | 콘텐츠 계약·호환·정산·자산 연결 |

표에 없는 파생 관계도 각 항목의 `근거` 열에 정확한 요구사항 ID를 우선 기록한다. 하나의 ID는 부분 승인하지 않는다. 사용자가 묶인 매개변수 중 일부만 다르게 판단하면 해당 행을 별도 ID로 분리한 뒤 각각 승인한다.

## 11. 사용자 리뷰 순서

1. `PRD-001`~`PRD-015`: 제품 정의와 범위
2. `PRD-016`~`PRD-028`: 사용자 환경과 성공 기준
3. `PRD-029`~`PRD-043`: 출시·운영·등급
4. `PRD-044`~`PRD-049`: 문서 품질과 추적성
5. `PRD-050`~`PRD-062`: 스토어 자산·지역 규정·출시 후 지원

## 12. 공식 근거의 적용 한계

- ISO 웹페이지는 표준의 공식 서지 정보와 공개 개요다. 유료 전문의 세부 조항 준수를 주장하지 않고 요구사항 분류·품질 검토의 참고 기준으로만 사용한다.
- WCAG 2.2는 웹 콘텐츠 표준이므로 Phaser Canvas 게임에 적용 가능한 인지·조작·가독성 원칙과 시험 항목만 참고한다.
- Steamworks의 파트너 전용·변경 가능 제출 필드, 출시 국가별 등급·소비자보호·확률형 요소 규정은 대상 지역과 출시 시점이 정해진 뒤 해당 공식 자료로 다시 검증한다.
- 게임의 재미, 밸런스, 세계관과 시각 방향은 표준이 결정하지 않는다. 사용자 승인과 플레이테스트·디자인 검증으로 결정한다.
