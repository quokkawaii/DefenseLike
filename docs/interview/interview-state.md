# DefenseLike 기획 인터뷰 상태

갱신일: 2026-10-06

## 현재 작업

2026-10-06 전체 기획 QA 발견 문제 인터뷰를 사용자 지시로 중단하고 개발을 진행한다. 남은 문제는 아래 `발견된 정본 충돌`의 `개발 중 보고 대상`에 둔다.

현재 결정:
B1 — 신규 프로필은 D등급 원소 5종에 더해 궁수·단법·전사·광법·도적의 D등급 유닛 5종도 활성화된 상태로 시작하며, 지급분은 강화 0단계·중복 0개다. `GAME-054`에 통합하고 `SYS-048`은 `GAME-054`를 참조하도록 정리했다.

직전 QA 인터뷰 결정:
사용자 제공 맵 배치 구조에 따라 기존 논리상 위·아래 필드를 각각 화면의 왼쪽·오른쪽에 대응시킨다. 몬스터는 왼쪽 위·오른쪽 위 포탈에서 생성되어 위쪽 중앙으로 이동하고, 중앙 공유 열을 함께 아래로 이동한 뒤 아래쪽에서 각자의 좌우 경로로 갈라져 바깥쪽 세로 경로를 통해 시작 지점으로 순환한다. 중앙 공유 열의 렌더 좌표는 같지만 두 경로 상태는 독립적으로 유지한다.

최신 맵 패치를 이전 설정과 충돌할 때 우선 적용한다. 중앙 공유 열의 스크롤은 선택한 필드의 경로 ID로 후보를 먼저 제한한 뒤 공간 판정을 수행하며, 반대 경로 몬스터와 진행에는 영향을 주지 않는다.

중앙 공유 열은 시각적으로 하나의 길로 표현하고 몬스터의 소속 경로를 별도 색상·문양·레인·개체 표식으로 구분하지 않는다. 소속 경로와 독립 상태는 내부 판정에만 사용한다.

`UX-203`은 기존 DM 인계에 따라 캐릭터 전체 동작에서 공통으로 사용하는 대표 키포즈 세트를 캐릭터마다 약 8개 제작하고, 각 애니메이션은 필요한 공통 키포즈와 중간 프레임을 사용해 기본 6프레임·복잡한 동작 최대 약 8프레임으로 완성하는 규칙임을 재확인했다.

기존 4차 기획 인터뷰 중단 지점:
`PRD-062`·`UX-109`에서 의무 라이선스 고지를 설치 폴더 최상위의 `THIRD_PARTY_NOTICES.txt` 한 곳에만 제공하기로 확정했다. 오류·크래시와 일반 버그의 공식 지원 경로 질문 전이다.
