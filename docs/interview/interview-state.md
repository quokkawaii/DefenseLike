- `GAME-178`은 시간 기반 인게임 재화의 지급 주기와 누적을 `미정`으로 두지만, `GAME-111`에서 시간 경과·층·플레이 시간에 따른 인게임 재화 지급을 이미 폐기하고 `확정`했다.

- `GAME-178` 정본의 상태와 문구 정리는 사용자 허락을 받은 뒤 수행한다.
