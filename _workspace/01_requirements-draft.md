# DefenseLike 기획 인터뷰 인계 기록

- 갱신일: 2026-09-16
- 용도: 다음 기획 인터뷰를 중단 지점부터 이어가기 위한 임시 인계
- 정본: 확정된 인터뷰 결과는 `docs/game-req.md`, `docs/system-req.md`, `docs/design-req.md`, `docs/product-req.md`에서 관리한다.
- 상태 규칙: 인터뷰에서 사용자가 결정한 내용은 `확정`, 항목별 리뷰를 통과한 내용은 `승인`으로 관리한다.
- 이 파일에는 완료 범위를 나열하지 않고, 어디까지 진행하다가 멈췄는지와 다음 진행 순서만 기록한다.

## 현재 중단 지점

- 공격 대상 선정, 투사체와 광역 공격의 공통 동작을 세부적으로 인터뷰하던 중, 캐릭터 종류와 역할이 먼저 정해져야 한다는 사용자 지적으로 순서를 바로잡았다.
- 이후 사용자가 `docs/characters.md`에 정리한 궁수·단법·전사·광법·도적의 초기 설정을 읽고 `GAME-254`~`GAME-259`에 반영했다.
- 현재는 이 다섯 캐릭터를 기준으로 **콘텐츠·캐릭터 정의를 점검하다가 멈춘 상태**다. 캐릭터 단계 전체가 끝났다고 간주하지 않는다.
- 공통 공격 규칙과 캐릭터별 예외가 일부 정본에 들어가 있지만, 아래 단계 순서에 따라 다시 분류하고 빠진 결정만 인터뷰해야 한다.

## 다음에 시작할 일

1. `docs/characters.md`와 네 정본 문서를 대조해 다섯 캐릭터의 종류·역할·공격 분류가 서로 맞는지 확인한다.
2. 이미 `확정` 또는 `승인`된 내용은 질문하지 않는다.
3. 콘텐츠·캐릭터 정의에서 빠진 결정이 있으면 그것부터 한 번에 하나씩 질문한다.
4. 해당 단계에서 더 물을 내용이 없다는 것을 확인한 뒤에만 기본 행동 단계로 넘어간다.
5. 이후에도 각 단계를 건너뛰지 말고 아래 진행 순서를 따른다.

## 기획 인터뷰 진행 순서

1. **콘텐츠·캐릭터 정의**
   - 출시 또는 현재 기획 범위에 들어가는 캐릭터·몬스터·보스·함정 등 콘텐츠 종류와 역할을 정한다.
   - 캐릭터는 우선 궁수·단법·전사·광법·도적의 다섯 종류를 기준으로 점검한다.
2. **기본 행동**
   - 각 콘텐츠의 평상시 대상 선정, 이동, 기본 공격, 자원 획득 등 등급과 무관한 기본 행동을 정한다.
3. **등급별 변화**
   - D~S 등급에서 사거리, 횟수, 범위, 지속시간, 기능이 어떻게 달라지는지 정한다.
   - 등급별 수치와 기능 변화를 구분하며, 아직 정할 수 없는 밸런스 수치는 마지막 단계로 미룬다.
4. **공격·스킬 세부 규칙**
   - 발동 조건, 대상, 시전 중 행동, 타격 방식, 투사체, 범위 판정과 효과 적용 시점을 정한다.
   - 모든 공격을 하나의 공통 모양이나 방식으로 강제하지 않고 캐릭터별 정의를 따른다.
5. **예외**
   - 대상 사망·이탈, 빗나감, 취소, 중복 발동, 동시 사건, 최대 상태와 실패 시 처리를 정한다.
   - 공통 규칙과 캐릭터 전용 예외가 충돌하면 원본 ID를 함께 제시하고 사용자에게 결정받는다.
6. **밸런스 수치**
   - 피해량, 능력치, 공격속도, 재사용 대기시간, 비용, 확률, 강화 재료 수량과 상한·하한을 정한다.
   - 캐릭터와 동작 규칙이 확정되기 전에는 수치를 임의로 만들지 않는다.

## 현재 순서에 배치할 기존 미정 사항

- 콘텐츠·캐릭터 정의: 몬스터 종족·종류·구간 구성, 보스 종류·능력, 함정 종류와 역할
- 기본 행동: 캐릭터별 기본 공격의 정확한 방식, 몬스터·보스의 이동과 행동, 함정의 기본 수명주기
- 등급별 변화: 캐릭터 D~S 변화, 유닛·원소 강화 단계와 승급 효과
- 공격·스킬 세부 규칙: 캐릭터별 스킬 판정, 상태효과, 함정·패링 효과의 적용 시점
- 예외: 상태효과 중첩, 대상 사망·미적중, 동시 사건, 최대 강화·최고 등급 처리
- 밸런스 수치: `GAME-057`, 원소 상성 수치, 뽑기·강화·경제·몬스터·보스·함정 수치

위 목록은 질문지가 아니라 정본의 기존 `미정` 사항을 진행 단계에 배치한 안내다. 질문을 만들기 전에는 반드시 네 정본에서 최신 상태와 중복 여부를 다시 확인한다.

## 인터뷰 및 반영 규칙

- 한 번에 질문 하나만 제시한다.
- 질문에는 사용자가 비교할 수 있는 선택지를 제공하되, 문서에 없는 답을 정답처럼 유도하지 않는다.
- 질문 전에 네 정본 문서 전체에서 같은 의미의 기존 항목과 이미 결정된 답을 검색한다.
- 같은 의미의 항목은 새 ID를 만들지 않고 기존 항목을 보완한다. 별도 책임이나 검증 경계가 있을 때만 새 ID를 만든다.
- 답변마다 관련 정본에 반영하고 문서 간 충돌·중복·참조 영향을 확인한다.
- 답변하지 못한 항목은 `미정`으로 유지한다.
- 매 질문 뒤에 임의의 전체 잔여 인터뷰 수를 표시하지 않는다. 대신 현재 단계와 다음 결정 지점을 보고한다.
- `_workspace`는 매 답변마다 갱신하지 않는다. 세션을 멈추거나 중단 지점과 재개 순서가 달라졌을 때 한꺼번에 갱신한다.
